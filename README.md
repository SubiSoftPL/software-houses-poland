## How this list is made

This is an **editorially curated** directory. Companies are selected based on publicly available information about their experience, portfolio, specialisations and reputation. It is **not** a paid ranking — there is no pay-for-placement, and the order is not a strict score. To suggest a company, a correction, or to request inclusion, [open an issue](https://github.com/SubiSoftPL/software-houses-poland/issues) or submit a pull request.
